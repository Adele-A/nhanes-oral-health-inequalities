# Data dictionary — Power BI star schema (`dashboard/data/`)

All files are UTF-8 CSV with `.` as the decimal separator, generated by
`R/06_exports.R` from the **pre-computed, design-based** estimates. Power BI cannot compute
design-based variance, so it receives only finished estimates with confidence intervals —
never weighted microdata. Proportions (`estimate`, `ci_*`) are on the 0–1 scale; the
`*_pct` columns are the same values ×100 for display. All values describe **U.S. adults 20+,
NHANES 2017–2018**, and are **associations, not causal effects**.

## Fact tables

### `fact_estimates.csv`
Weighted prevalence estimates across outcomes and sociodemographic groups.

| Column | Type | Description |
|---|---|---|
| `outcome` | text | Outcome name (FK → `dim_outcome.outcome`) |
| `group_variable` | text | Grouping variable (FK → `dim_group_variable`) |
| `group_level` | text | Level within the grouping variable |
| `estimate` | number | Weighted proportion (0–1) |
| `ci_low`, `ci_high` | number | 95% Korn–Graubard CI bounds (0–1) |
| `se` | number | Design-based standard error |
| `n_unweighted` | integer | Unweighted denominator for the cell |
| `df` | integer | Design degrees of freedom |
| `reliability_flag` | text | `reliable` / `review` / `suppress` (FK → `dim_reliability`) |
| `reliable` | boolean | TRUE if meets NCHS standards |
| `estimate_pct`, `ci_low_pct`, `ci_high_pct` | number | Same as above ×100 (percentage display) |
| `estimate_id` | integer | Surrogate key |

### `fact_model_coefficients.csv`
Adjusted regression estimates (associations with the primary outcome).

| Column | Type | Description |
|---|---|---|
| `model` | text | `Unadjusted: <var>`, `Adjusted (b)`, `Adjusted + oral health (c)` |
| `measure` | text | `OR` (odds ratio) or `PR` (prevalence ratio) |
| `term` | text | Model term (coefficient name) |
| `estimate` | number | OR or PR (exponentiated coefficient) |
| `ci_low`, `ci_high` | number | 95% CI (design df) |
| `p_value` | number | Wald p-value |
| `covariate` | text | Parsed covariate name |
| `level` | text | Parsed level within the covariate |
| `coef_id` | integer | Surrogate key |

### `fact_reason_for_visit.csv`
Reason for the last dental visit, among adults with a visit in the past 12 months
(weighted %). Columns: `group_variable`, `group_level`, `reason`, `weighted_pct`,
`weighted_pct_se`, `n_unweighted`.

### `fact_unmet_need_reasons.csv`
Reasons self-reported unmet dental need could not be met (`OHQ780A–K`), among adults
reporting unmet need (weighted %, check-all-that-apply). Columns: `reason_var`,
`reason_label`, `weighted_pct`, `ci_low`, `ci_high` (percentage scale), `n_endorsed`.

## Dimension tables

- **`dim_outcome.csv`** — `outcome`, `definition`, `higher_means` (how to read a higher value).
- **`dim_reliability.csv`** — `reliability_flag`, `meaning` (NCHS Parker et al. 2017 standard).
- **`dim_group_variable.csv`** — `group_variable` (list of grouping variables).

## Relationships

- `fact_estimates[outcome]` → `dim_outcome[outcome]`
- `fact_estimates[group_variable]` → `dim_group_variable[group_variable]`
- `fact_estimates[reliability_flag]` → `dim_reliability[reliability_flag]`
